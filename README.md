# Viajes Chile

Landing page desarrollada para la prueba Viajes Chile.

## Tecnologías utilizadas
- HTML5
- CSS3
- Bootstrap
- JavaScript
- jQuery
- Font Awesome
- Google Fonts

## Funcionalidades
- Navbar con navegación
- Carrusel de imágenes
- Sección Quiénes Somos
- Tarjetas de destinos destacados
- Formulario de contacto
- Footer con redes sociales
- Diseño responsivo

Proyecto desarrollado como parte del módulo Fundamentos de Desarrollo Front-End.
